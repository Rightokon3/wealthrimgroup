# WealthRim Group of Companies

A multi-page investor-facing corporate website for WealthRim Group of Companies.

## What it does

Presents the company to prospective investors and walks qualified visitors through an investor application.

## Features

- **Multi-page marketing site** — company overview, services, and investor-facing content
- **Multi-step investor form** — an animated, multi-step application flow built with Framer Motion, designed to keep a long form from feeling long
- **Backend-connected submissions** — investor applications stored via Supabase

## Tech stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Backend:** Supabase
